# AI_NOVELIST_TOOLS_DIR 回退兼容方案

## 背景

启动器（launcher）和后端（本体）是两条独立的生产线：

- **新启动器**：会在启动后端进程时设置环境变量 `AI_NOVELIST_TOOLS_DIR`，指向 `exe同级/bin/`
- **旧启动器**：不会传递该环境变量
- **后端（新版本）**：`get_bin_dir()` 要求必须存在 `AI_NOVELIST_TOOLS_DIR`，否则直接崩溃

问题：新后端已经分发到用户手上，但用户手中的启动器还是旧版本，导致后端启动时报错：

```
RuntimeError: 环境变量 AI_NOVELIST_TOOLS_DIR 未设置，请通过启动器运行项目
```

## 临时修复方案（2026-06-04）

### 修改的文件

#### 1. `backend/settings/paths.py` — `get_bin_dir()`

**查找优先级**（从高到低）：

1. 环境变量 `AI_NOVELIST_TOOLS_DIR`（由启动器传入）
2. 项目根目录下的 `bin/`（旧版本布局，兼容直接运行）
3. 冻结模式（PyInstaller）：`exe同级/bin/`
4. 都找不到时 → 返回项目根目录的 `bin/` 路径（即使不存在），记录 warning 日志，让 `_get_executable()` 回退到系统命令

不再抛 `RuntimeError`。

#### 2. `backend/settings/settings.py` — `Settings.__init__()` 初始化顺序

**改动前**：

```python
self._get_executable('node.exe')  # 第1步：找可执行文件（需要 AI_NOVELIST_TOOLS_DIR）
self.env_manager = EnvManager(...) # 第2步：加载 .env
```

**改动后**：

```python
self.env_manager = EnvManager(...) # 第1步：先加载 .env（将 AI_NOVELIST_TOOLS_DIR 注入 os.environ）
self._get_executable('node.exe')  # 第2步：再找可执行文件
```

这样，如果用户在 `.env` 中配置了 `AI_NOVELIST_TOOLS_DIR`，也能被正确读取。

### 涉及的回退链

```
get_bin_dir()
  │
  ├─ os.environ["AI_NOVELIST_TOOLS_DIR"]  ─── 启动器传入（优先）
  │
  ├─ 项目根目录/bin/                       ─── 旧版本布局（兼容）
  │
  ├─ exe同级/bin/                         ─── 冻结模式（PyInstaller）
  │
  └─ 返回 project_root/bin/ (不存在也返回)  ─── _get_executable() 会回退到系统命令
                                                     (如 node.exe → node)
```

## 后续清理计划

> ⚠️ **这些是临时兼容代码，后续必须全部删除！**

当所有用户都升级到新启动器后（启动器已改为传递 `AI_NOVELIST_TOOLS_DIR`），需要：

### 删除的回退逻辑

1. **`paths.py:get_bin_dir()`** — 删除第2、3、4优先级（`bin/` 目录查找），恢复为只读取环境变量，找不到就抛 `RuntimeError`

   应恢复为：
   ```python
   def get_bin_dir():
       tools_dir = os.environ.get("AI_NOVELIST_TOOLS_DIR")
       if tools_dir:
           return Path(tools_dir)
       raise RuntimeError("环境变量 AI_NOVELIST_TOOLS_DIR 未设置，请通过启动器运行项目")
   ```

2. **`paths.py`** — 删除新增的 `import logging`（如果其他地方不再使用）

### 保留的改动

- **`settings.py` 初始化顺序调整**（`EnvManager` 先于 `_get_executable`）— 这本身是合理的，即使启动器传入环境变量，先加载 `.env` 也没有副作用，应该保留。

### 判断是否可以清理的标志

当启动器代码中以下位置已确认实现 `AI_NOVELIST_TOOLS_DIR` 传递：

- `launcher/internal/backend/backend.go`（或等效文件）中启动后端进程时设置了该环境变量
- 且所有活跃用户的启动器都已升级到该版本
