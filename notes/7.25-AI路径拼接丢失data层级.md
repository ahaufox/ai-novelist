# AI 调用工具时偶尔丢失 /data/ 层级

## 现象

AI 在调用文件操作工具（read/write/edit/glob/grep）时，偶尔会少拼接一个 `/data/` 层级。

例如：
- 正确路径：`F:/1/ai-novelist/data/演示文件.md`
- AI 实际传入：`F:/1/ai-novelist/演示文件.md`（缺少 `data/`）

该 bug **偶发**，无法稳定复现。

## 链路分析

### 文件树展示给 AI 的格式

当前代码在 [`format_tree_for_prompt`](backend/file/smart_file_tree.py:351) 中：

```
工作区根目录：F:/1/ai-novelist/data/
[项目文件结构 - 完整文件树]
统计: 共5 项

演示文件.md
folder1/
folder1/file1.txt
```

格式是：**先给出根目录绝对路径，再给出相对于根目录的路径列表**。

AI 需要自行拼接：`根目录 + 相对路径` → 绝对路径。

### 路径解析

[`resolve_file_path`](backend/file/file_service.py:18) 对相对路径会基于 `DATA_DIR`（= `{exeDir}/data`）拼接，对绝对路径直接使用。

### 环境变量

启动器 [`BuildEnvMap`](launcher/internal/env/envars.go:86) 设置：
```
AI_NOVELIST_DATA_DIR = {exeDir}/data
```

`DATA_DIR` 已包含 `data` 层级，无问题。

## 尝试过的排查

1. 在 `system_prompt_builder.py` 打印 `data_path` 和格式化后的文件树 — 路径完全正常
2. 在 `chat_api2.py` 打印发给 AI 的完整消息列表 — 根目录包含 `data/`
3. 在 `chat_api2.py` 打印 AI 调用工具时的实际参数 — 未复现 bug
4. 在 `file_service.py` 打印每次路径解析的输入输出 — 正常

**加了日志后数次测试均无法复现**，怀疑是 AI 模型偶发性"犯浑"。

## 可能的解决思路

### 方案：文件树全部使用绝对路径

当前格式（根目录 + 相对路径）：
```
工作区根目录：F:/1/ai-novelist/data/
演示文件.md
folder1/file1.txt
```

改为每条都是绝对路径：
```
F:/1/ai-novelist/data/演示文件.md
F:/1/ai-novelist/data/folder1/
F:/1/ai-novelist/data/folder1/file1.txt
```

这样 AI 不需要自行拼接，直接使用展示的路径即可，消除 AI 拼错的可能。

改动点：修改 [`format_tree_for_prompt`](backend/file/smart_file_tree.py:351) 中的 `collect_paths` 函数，让每条路径都以根目录为前缀。


### 其他方案：不提供文件树

只有ai自行使用工具获取路径，才显示绝对路径的文件树
